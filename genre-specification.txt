  _________________________________________________
 /                                                 \
(   Sean Colsen's music genre name specification    )
 \_________________________________________________/

Purpose:
  * Given a large number of musical pieces (songs), we would like to develop a
    system of categorizing them such that we can efficiently and 
    straightforwardly retrieve a set of songs that is suitable to a given mood
    and contains a diverse mix of artists.
  * This document specifies a format for generating one string that encapsulates
    a subjective representation of the "genre" for each song. This string is 
    called the "genre string"
  * With all songs having a genre string, we can easily query the set of genre 
    strings to match a variety of constraints. 

How to:
  * Listed below are many genre elements (enclosed with curly braces) which 
    represent various measurements that can be taken (qualitatively) from each
    song.
  * Each element has many values which are listed below the element name.
  * Each value has an abbreviation (listed first) and then a description (listed
    after one space, one dash, and one space).
  * The complete genre string for each song is formed by concatenating all of
    the applicable genre values in the order they are listed on this page.
  * Also, as a reference, there are hyper-values listed at the end of this
    specification that match genre values in multiple elements. Hyper-values 
    are not written into the genre string.

Examples:
  * a genre string of "e2.d3.t3.m1.p3.rdub.nblk.vcs.lne.ibrs" might represent a
    chill song with decent rhythm, some electronic elements, very underground,
    singing vocals throughout the song that aren't in english, some rhythm 
    constructions from dub music, some melody constructions from balkan music, 
    and brass instruments.
_______________________________________________________________________________

   ,~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~.
  {  required elements, one value only  }
   `~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~'

{Energy}
e1 - really chill, sleepy, relaxed
e2 - chill, hang out, relaxed
e3 - (DEFAULT) some energy, but not a whole lot
e4 - lots of energy
e5 - really crazy

{Dance}
.d1 - not very much rhythm
.d2 - (DEFAULT) normal amount of rhythm, foot tapping and finger tapping
.d3 - very strong rhythm, head bobbing and shoulder moving difficutlt to avoid
.d4 - worthy of full-body dancing
.d5 - crazy hard dancing difficult to avoid

{Technology}
.t1 - everything acoustic
.t2 - some amplified sound like electric guitar
.t3 - (DEFAULT) a mix of acoustic stuff and electronic stuff
.t4 - mostly electronic stuff
.t5 - everything electronic

{Mainstream}
.m1 - very underground sounding
.m2 - (DEFAULT) indie sounding
.m3 - kind of indie, wouldn't be out of place on the radio though
.m4 - pretty mainstream sounding, but maybe not everyone has heard it
.m5 - top 40s

{Presence-of-vocals}
.p0 - none
.p1 - abstract or minimalistic
.p2 - (DEFAULT) somewhat present vocals
.p3 - present vocals
.p4 - vocals are the main focus of the track

{Scale}
.smaj    - major
.sminnat - natural minor
.sminhar - harmonic minor
.sminmel - melodic minor
.sdblhar - double harmonic
.shungyp - hungarian gypsy
.sphrygd - phrygian dominant
.sphrygn - phrygian
.sunk    - unknown
.s####   - a numerical representation of the scale as the decimal equivalent of a big-endian
           binary number with every active interval set to 1. For example, a major scale would
           be 0b101010110101 which equals 2741, so we would write ".s2741". Similarly, the major
           pentatonic scale is 0b001010010101 which equals 661 so we would write ".s0661". Note
           that the decimal number should be zero padded to 4 decimal places when written into
           the genre string.
